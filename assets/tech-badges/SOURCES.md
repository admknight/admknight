# Tech Arsenal vector badge sources

The 26 self-contained SVG badges are generated by
[\`tools/build_tech_badges.py\`](../../tools/build_tech_badges.py).
Their technology names and category assignments match the GitHub profile.

- **Simple Icons**, snapshot \`98820a4dc8c363ca72fa2c0d294ea4a0a9bba75d\`:
  <https://github.com/simple-icons/simple-icons> (CC0-1.0).
- **CSS3 mark**: Simple Icons \`13.21.0\`, \`icons/css3.svg\`.
- **Visual Studio Code mark**: Simple Icons \`11.0.0\`, \`icons/visualstudiocode.svg\`.

Brand trademarks belong to their respective holders. Badge layout,
backgrounds, accents, text, and sizing are generated locally; each SVG
embeds its vector logo rather than loading any external icon at runtime.
