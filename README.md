## 🚀 Flagship Project

### [Adam Knight Mega Repo — CloudStream Extensions & Plugins](https://github.com/admknight/CloudstreamExtensions)

An automatically maintained CloudStream extensions repository with upstream aggregation, version-aware deduplication, package verification, custom-provider builds, runtime health monitoring, publication safety gates, and a public dashboard.

**Highlights**

- Aggregates many upstream CloudStream repositories into one installable feed.
- Uses version-aware deduplication and source priority rules.
- Verifies published package availability before production release.
- Builds and publishes locally maintained custom providers.
- Tracks provider/site health separately from package health.
- Publishes project status and repository information through GitHub Pages.

**Stable milestone:** [v1.0.0 — First Stable Release](https://github.com/admknight/CloudstreamExtensions/releases/tag/v1.0.0)
